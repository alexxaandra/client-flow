Πολιτική Απορρήτου

Τελευταία ενημέρωση: Σεπτέμβριος 2026 (v2)  ·  AlphaDevs

1. Εισαγωγή

Η εφαρμογή ClientFlow («εμείς», «η εφαρμογή») σέβεται την ιδιωτικότητά σας. Αυτή η πολιτική απορρήτου περιγράφει ποιες πληροφορίες συλλέγουμε, πώς τις χρησιμοποιούμε και πώς τις προστατεύουμε. Με τη χρήση της εφαρμογής αποδέχεστε τους όρους αυτής της πολιτικής.

2. Πληροφορίες που συλλέγουμε

• Διεύθυνση email για τη δημιουργία και διαχείριση του λογαριασμού σας • Επαγγελματικά δεδομένα που εισάγετε εσείς (ονόματα πελατών, αριθμοί τηλεφώνου, διευθύνσεις, ραντεβού, σημειώσεις) • Ρυθμίσεις εφαρμογής (θέμα, νόμισμα, προτιμήσεις) • Expo Push Token — ένα μοναδικό αναγνωριστικό συσκευής που χρησιμοποιείται αποκλειστικά για την αποστολή ειδοποιήσεων push. Δεν περιέχει προσωπικά στοιχεία. Δεν συλλέγουμε δεδομένα τοποθεσίας, επαφών τηλεφώνου, φωτογραφιών ή άλλων αρχείων χωρίς τη ρητή συγκατάθεσή σας. Δεν χρησιμοποιούμε cookies ή trackers τρίτων.

3. Πώς χρησιμοποιούμε τα δεδομένα

Τα δεδομένα σας χρησιμοποιούνται αποκλειστικά για: • Τη λειτουργία και βελτίωση της εφαρμογής • Τον συγχρονισμό των δεδομένων σας μεταξύ συσκευών μέσω Firebase • Την αποκατάσταση των δεδομένων σας σε νέα συσκευή Δεν πουλάμε, νοικιάζουμε ή μοιραζόμαστε τα δεδομένα σας με τρίτους για οποιονδήποτε σκοπό.

4. Αποθήκευση δεδομένων

Τα δεδομένα σας αποθηκεύονται: • Τοπικά στη συσκευή σας για άμεση πρόσβαση χωρίς σύνδεση • Κρυπτογραφημένα στο Firebase (Google Cloud Infrastructure) για συγχρονισμό και ασφαλή αντίγραφα Η πρόσβαση στα δεδομένα σας στο cloud είναι δυνατή μόνο από εσάς. Το Firebase συμμορφώνεται πλήρως με τα πρότυπα GDPR, ISO 27001 και SOC 2.

5. Ασφάλεια

• Οι κωδικοί πρόσβασης κρυπτογραφούνται από το Firebase Authentication — δεν τους βλέπουμε ποτέ • Κανείς άλλος χρήστης δεν έχει πρόσβαση στα δεδομένα σας • Όλες οι επικοινωνίες χρησιμοποιούν κρυπτογράφηση TLS/HTTPS • Οι κανόνες ασφαλείας Firestore επιτρέπουν πρόσβαση μόνο στον κάτοχο του λογαριασμού

6. Διαγραφή δεδομένων

Μπορείτε να ζητήσετε τη διαγραφή του λογαριασμού σας και όλων των σχετικών δεδομένων ανά πάσα στιγμή.

7. Δικαιώματα GDPR

Ως κάτοικος της Ευρωπαϊκής Ένωσης έχετε τα εξής δικαιώματα: • Πρόσβαση στα δεδομένα που διατηρούμε για εσάς • Διόρθωση ανακριβών δεδομένων • Διαγραφή των δεδομένων σας («δικαίωμα στη λήθη») • Φορητότητα δεδομένων — εξαγωγή σε JSON μέσω της εφαρμογής • Περιορισμός της επεξεργασίας • Εναντίωση στην επεξεργασία Για οποιοδήποτε αίτημα GDPR επικοινωνήστε στο: alphadevs@hotmail.com

8. Ειδοποιήσεις Push

Η εφαρμογή ενδέχεται να σας αποστέλλει ειδοποιήσεις push για ενημερώσεις, νέες λειτουργίες ή σημαντικές αλλαγές. Για τον σκοπό αυτό: • Αποθηκεύουμε το Expo Push Token της συσκευής σας στο Firebase • Δεν χρησιμοποιείται για διαφήμιση ή κοινοποίηση σε τρίτους • Μπορείτε να αποσύρετε τη συγκατάθεσή σας ανά πάσα στιγμή από τις ρυθμίσεις ειδοποιήσεων της συσκευής σας • Η απόσυρση συγκατάθεσης δεν επηρεάζει τη λειτουργία της εφαρμογής

9. Τρίτα μέρη

Η εφαρμογή χρησιμοποιεί τις εξής υπηρεσίες τρίτων: • Firebase (Google) — αυθεντικοποίηση και αποθήκευση δεδομένων • Expo (Expo.dev) — υποδομή ειδοποιήσεων push. Το Expo λαμβάνει μόνο το Push Token για δρομολόγηση ειδοποιήσεων και δεν αποθηκεύει περιεχόμενο μηνυμάτων • Firebase Cloud Messaging (Google) — παράδοση ειδοποιήσεων σε Android συσκευές • OpenStreetMap / Nominatim — γεωκωδικοποίηση διευθύνσεων για τον χάρτη (αποστέλλονται μόνο διευθύνσεις, χωρίς προσωπικά στοιχεία) Όλες οι υπηρεσίες συμμορφώνονται με το GDPR.

10. Αλλαγές στην πολιτική

Ενδέχεται να ενημερώνουμε αυτή την πολιτική περιοδικά. Σημαντικές αλλαγές θα γνωστοποιούνται μέσω της εφαρμογής. Η ημερομηνία τελευταίας ενημέρωσης εμφανίζεται πάντα στην κορυφή αυτής της σελίδας. Η συνέχιση χρήσης της εφαρμογής μετά από αλλαγές συνιστά αποδοχή της νέας πολιτικής.
